# Test: LaTeX 数学公式风格

## 测试目标

验证公式排版符合 lailai 习惯：`$...$` 分隔符、数学语言、规范记号、无多余空格、多行对齐、公式内无裸中文 / Unicode。

## 输入任务

让被测 AI 写一段中文推导，含以下会诱发常见错误的点：一个赋值（`i \to i+1`）、一个取模、一个向下取整、一个分数、一个三角 / 对数函数、一个 `\gcd`、一个带中文下标的量（如「总收益」），以及一个 `\begin{aligned}` 两行推导。面向有基础的读者。

## 期望输出特征

- 行内 `$...$`、行间 `$$...$$`，行间 `$$` 单独成行，前一行必须以全角冒号「：」结尾。
- 数学语言：赋值 `\to`、取模 `\bmod`、取整 `\lfloor x\rfloor`、`\gcd(a,b)`。
- `\frac{}{}` 分子分母都带花括号；函数名后不加花括号（`\ln x`、`\sin\theta`）。
- 运算符 / 命令两侧无多余空格；无 `\,` `\quad` 等手动间距。
- 多行分支缩进 2 空格、`&` 两侧各一空格、非末行以 ` \\` 结尾。
- 公式及多行公式各分支末尾均无句号、逗号等句读；`\begin` / `\end` 各自单独成行。
- 公式内中文套 `\text{}`（下标也不例外），无 `×` `−` `°` 等 Unicode。
- 普通散文数字保持纯文本；OI 题解可沿用个人数值量数学化例外，但日期仍是纯文本。

## 评分标准（0～5）

- 0：用 `\(...\)` / `\[...\]`、`\frac s2`、`[x]` 取整、裸中文下标、满是多余空格。
- 3：主体对，1～2 处偏差（如 `\dfrac`、`\sin{\theta}`、`&` 空格不对）。
- 5：分隔符 / 记号 / 空格 / 多行 / 无 Unicode 全部合规。

## 常见失败表现

- 站内用 `\(...\)`；`a^2 + b^2 = c^2` 两侧留空格。
- `\frac12` / `\frac s2` 省花括号；赋值用 `=`、取模用 `%`。
- 取整写 `[x]`、gcd 写 `(a,b)`；函数名写 `\sin{\theta}`。
- 中文下标 `v_{正}`；公式里出现 `×` / `°`。

## 客观检查项（可机械判定，全过才算通过）

- [ ] 只用 `$...$` / `$$...$$`，不含 `\(` / `\[`。
- [ ] 行间公式前文以全角冒号引出；公式和每个分支末尾均无句读。
- [ ] 无 `\dfrac`；`\frac` 分子分母均带花括号（无 `\frac12` / `\frac s2`）。
- [ ] 赋值用 `\to` / `\gets`（非 `=`），取模用 `\bmod` / `\pmod`（非 `%`）。
- [ ] 取整用 `\lfloor…\rfloor`（无 `[x]`），gcd 用 `\gcd(…)`（无裸 `(a,b)` 表 gcd）。
- [ ] 函数名后无花括号（`\sin\theta` 非 `\sin{\theta}`）；无 `\,` `\;` `\quad` 等手动间距。
- [ ] `\begin` / `\end` 各自单独成行；`aligned` 分支缩进 2 空格、`&` 两侧各一空格、非末行 ` \\` 结尾。
- [ ] 公式内无裸中文（含下标，套 `\text{}`）、无 `×` `−` `°` `～` 等 Unicode 符号。

## 通过条件

主观评分 ≥ 4 分，**且**上述客观检查项全部通过。
