# Test: 邮件格式（中 / 英）

## 测试目标

验证输出符合 lailai 的邮件规范：一封一事、先事由后背景、结构完整、措辞得体、无 AI 腔。

## 输入任务

让被测 AI 写一封中文正式邮件：高二学生向班主任李老师申请信息学竞赛集训期间请假两天，说明事由、时间、补课安排，并附上集训通知。（英文变体：向教授请求一封推荐信，检查项同构切到半角标点与 `Dear …,` / `Best regards,`。）

## 期望输出特征

- 主题具体、含标识，不留空，如「[请假申请] 信息学集训请假两天 ——张三」。
- 称呼顶格、末尾冒号（中文）/ 逗号（英文）；开头一句自我说明 + 事由。
- 先结论后细节；请求明确，时间 / 材料单独列出；附件在正文提及。
- 结尾敬语 +「此致 / 敬礼」，签名含身份、联系方式、日期各占一行。
- 句子简短、主动语态、无套话、无 emoji、无感叹号堆叠。

## 评分标准（0～5）

- 0：无主题或空泛主题、缺敬语 / 签名、满是套话、一大段糊在一起。
- 3：结构基本全，但有 1～2 处（漏附件提及 / 请求不明确 / 个别套话）。
- 5：六段结构完整、请求明确、标点得体、零 AI 腔。

## 常见失败表现

- 「希望这封邮件能找到您」「打扰啦」「您好呀」等套话开场。
- 主题写「你好」或留空；请求含糊，没给时间 / 材料。
- 中文邮件用半角标点或混入 emoji；缺结尾敬语或签名。
- 背景铺垫一大段才说事由。

## 客观检查项（可机械判定，全过才算通过）

- [ ] 有具体主题行，非空、非「你好」。
- [ ] 称呼单独成行，中文以冒号结尾 / 英文以逗号结尾。
- [ ] 有结尾敬语（中文「此致 / 敬礼」或英文 `Best regards,` 等）。
- [ ] 有签名，含身份与联系方式。
- [ ] 附件在正文被提及。
- [ ] 中文邮件全角标点、英文邮件半角标点；无 emoji、无 `！！`。
- [ ] 不含「希望这封邮件」「打扰」「在当今」等套话。

## 通过条件

主观评分 ≥ 4 分，**且**上述客观检查项全部通过。
