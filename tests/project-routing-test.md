# Test: 仓库规范路由

## 新建仓库

让 Agent 使用本 Skill 创建一个公开仓库。应先读取 `lailai-template/SETUP.md`，由模板
提供初始化、验收与清理流程；本 Skill 只补充个人表达与代码风格。
规范无法读取时，应明确缺失，不能凭印象复建一套标准并宣称严格合规。

## 维护现有 README

只给 Agent 一个已有项目及本 Skill，让它更新 README 与 GitHub 元数据。应读取项目
内部规则及模板中的对应标准；即使项目已经清理初始化文档，路由仍然有效。
个人风格检查通过不能替代模板仓库检查，模板检查也不能替代实际项目测试。

## 记录偏差

指出 README 结构与模板不符并要求维护。应将仓库标准、示例和通用检查修正在模板中，
不在本 Skill 的 profile、reference 或 checker 重新维护同一规则。
