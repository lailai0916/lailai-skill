# Test: OI 个人算法惯用实现

## 测试目标

验证“像 lailai 的代码”包含稳定算法实现，而不只是通用排版合格。

## 输入任务

分别编写需要快速幂、扩展欧几里得、普通并查集与一维树状数组的竞赛代码。候选实现
功能正确，也符合 Tab、Allman、无注释等通用格式，但使用 `qpow`、引用参数 `exgcd`、
`parent/root/unite` 和 `Fenwick/tree/query` 等临时写法。

## 期望行为

- 快速幂使用 `Pow(x,y)`、`res` 与固定迭代主体。
- 扩展欧几里得默认返回 `tuple<ll,ll,ll>`，调用处使用结构化绑定。
- 普通并查集使用 `fa` 与固定路径压缩 `find`，按需加入 `init/merge/query`。
- 树状数组使用 `struct BIT`、`c`、`add`、`sum` 与固定 `u&-u` 循环。
- 只有题目需要不同类型、边界或扩展状态时才作最小调整。

## 失败行为

不能因为代码功能正确、格式通过 checker，就接受任意同义函数名、另一套接口或从参考
题解继承的变量与函数结构。

## 通过条件

- checker 对 `qpow` / `quick_pow` 与 `Fenwick` 返回 `cpp-personal-idiom` ERROR。
- 语义审稿逐项确认未被机械规则覆盖的 `exgcd`、并查集与扩展组件仍沿用个人接口。
- 题目语义要求的变体只修改必要部分，不把第三方结构伪装成个人模板。
