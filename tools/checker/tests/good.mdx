## 前缀和

**前缀和**（Prefix Sum）把前 $k$ 项和预处理出来，使区间求和从 $O(n)$ 降到 $O(1)$。

定义 $S_k=\sum_{i=1}^{k}a_i$，则区间 $[l,r]$ 的和为 $S_r-S_{l-1}$。

行间公式如下：

$$
\begin{aligned}
  f(x) & =a \\
  & =b
\end{aligned}
$$

使用 GitHub 托管，日期 2025-09-16，时间 09:05:30。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll=long long;
const int N=100005;
int a[N];
int main()
{
	int n;
	cin>>n;
	n=static_cast<int>(n);
	ll sum=0;
	for(int i=1;i<=n;i++)cin>>a[i],sum+=a[i];
	cout<<sum<<'\n';
	return 0;
}
```
